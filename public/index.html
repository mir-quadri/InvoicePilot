How it works — honestly

Drafting is a deterministic engine in this build: it extracts client, amount, currency and due terms from your words and fills verified invoice data into templates. No hosted LLM key is required and no model output is invented. PayPal is abstracted behind an interface: by default every call goes to an in-memory mock sandbox (mock ids and mock-sandbox:// links). A live PayPal sandbox client for the Invoicing API v2 is included and is only used with sandbox credentials — see README. Invoices are stored in memory and clear on restart.
